# pingpong_zero

오산시 행정업무 관할·배분 지원시스템(근거 기반 주관·협조부서 추천) 프로토타입 작업 폴더입니다.
기획 배경은 [docs/AI_행정업무_관할배분_시스템_인계서.md](docs/AI_행정업무_관할배분_시스템_인계서.md)에 있습니다.

이 폴더에는 다음 결과가 있습니다.

1. **업무단위 정제**: 오산시 홈페이지 직원 업무 목록(1,263명) → 업무 6,149건 (`data/staff`, `data/tasks/tasks.csv`)
2. **근거법규 수집**: 행정기구 조례·시행규칙·의회 규칙의 분장사무 1,518항목과 인용 법령 (`data/laws`)
3. **업무별 근거 조항 연결**: 업무마다 같은 부서 분장사무 상위 3개와 타부서 근거 (`data/tasks/tasks_basis.csv`, `summary.md`)

## 다시 만들기

Python 3.12와 `olefile`(`py -m pip install --user olefile`)이 필요합니다.

```
py scripts/hwp2txt.py data/laws/raw/2168747_byeolpyo1-4.hwp data/laws/raw/2168747_byeolpyo1-4.tsv
py scripts/build_bunjang.py
py scripts/build_cited_laws.py
py scripts/parse_staff.py        # 페이지는 미리 받아 둠: curl --tlsv1.2 --tls-max 1.2 -A "Mozilla/5.0 …" (1.5초 간격)
py scripts/refine_tasks.py
py scripts/match_basis.py        # 약 40초
```

## 근거 연결 방식과 문턱값

- 유사도 = 글자 2-gram TF-IDF 코사인 + 공통 명사 1개당 0.05(최대 0.15). 같은 과의 분장사무 항목끼리만 비교해 상위 3개를 답니다.
- 무작위 표본 50건을 눈으로 보고 정했습니다. 0.45 이상은 거의 맞고, 0.15~0.45는 대체로 그럴듯하지만 검토가 필요하며, 0.15 미만은 대부분 틀렸습니다.
  - **직접근거**: 1위 ≥ 0.45 이고 2위보다 0.08 이상 앞섬
  - **후보**: 1위 ≥ 0.15
  - **근거없음**: 1위 < 0.15
  - **해당없음**: 유형이 총괄·서무·공통·근무상태인 업무
  - **동위임사무**: 행정복지센터(동) 업무. 조례 제19조(동의 직무)를 근거로 답니다.
  - **공통사무(총괄부서 근거)**: 공유재산·세입세출외현금·국민신문고·예산편성·사회복무요원·기록물·계약·회계·보안·조례 제개정·공약사항 등
    모든 부서가 스스로 하지만 조항은 총괄부서에만 있는 업무. 다른 부서 조항이 더 잘 맞고 업무에 해당 낱말이 있으면 이 라벨을 달고,
    근거1에 총괄부서(회계과·징수과·기획예산과·자치행정과 등)의 조항을, 근거2·3에 자기 부서 상위 2개를 둡니다. 목록 24개와 총괄부서는
    `match_basis.py`의 `COMMON_DUTIES`와 `summary.md`에 있습니다.
  - **타부서근거**: 전 부서 비교에서 다른 부서 조항 점수 ≥ 0.45 이고 자기 부서 최고점보다 0.15 이상 높음 → 경계 업무 후보.
    다만 공통사무, 일반 업무명, 과태료·과징금(부서마다 자기 법령으로 부과), 문구 틀(위원회·조성·공모사업·추진·관리 등)을
    지운 뒤 0.35 미만으로 떨어지는 경우는 표시하지 않습니다.
  - **일반 업무명**: 다섯 글자 미만이거나 '통계업무'·'청사관리'·'시설물 유지관리'처럼 일반적인 이름은 직접근거·타부서근거를 주지 않고 최대 후보로 둡니다.
- 점수는 문구가 닮은 정도일 뿐 관할 판단의 정답 확률이 아닙니다. 근거 문구는 모두 `분장사무.csv`에서 그대로 옮겼습니다.
- 유형 '근무상태'는 '교육'이 들어간 업무를 모두 잡으면 '평생교육' 같은 고유업무가 섞여서, 휴직·파견·공로연수·교육파견 같은 짧은 상태 표기만 해당하게 했습니다.
- 남은 타부서근거(본청 126건)에도 '힐링프로그램 운영 ↔ AI코딩교육 프로그램 운영'처럼 글자만 닮은 경우가 섞여 있으니 사람이 검토해야 합니다.

## 원칙과 한계

- 분장사무 문구는 원문 그대로입니다. 별표에서 이름이 여러 행에 나뉘어 적힌 경우(예: `기후환경`+`정책과`)만 이어 붙였고,
  조문을 호 단위로 나눌 때 〈개정 …〉 같은 연혁 표시는 항목 텍스트에서 뺐습니다(원문 열에는 그대로 있음).
- 인용 법령은 API 검색 결과의 법령명·약칭과 정확히 일치할 때만 `확인됨`입니다. 일치하지 않으면 `미확인`으로 두고 추측해 채우지 않았습니다.
- 시행규칙 API의 시행일자는 2026-09-18이지만 부칙(제1004호)은 2026-10-01 시행으로 적혀 있습니다.
- 동의 분장사무는 시행규칙 제13조②에 따라 "시장이 따로 위임한 사무"라 별표가 없고, 조례 제19조의 일반 직무만 넣었습니다.
- 조례 별표 1~5(`raw/2168779_byeolpyo1-5.hwp/.tsv`)는 기관 명칭·위치와 정원 기준표뿐이라 분장사무에는 넣지 않았습니다.
- 미확인 인용 법령 3건의 후보는 `cited_laws_candidates.csv`에 따로 적었습니다(검토 전이라 cited_laws.csv는 그대로).
