# 업무별 근거 조항 연결 요약

업무 6149건. 유사도 = 글자 2-gram TF-IDF 코사인 + 공통 명사 가산점(0.05/개, 최대 0.15).

## 문턱값과 규칙

- 직접근거: 1위 ≥ 0.45 이고 2위보다 0.08 이상 앞섬
- 후보: 1위 ≥ 0.15
- 근거없음: 1위 < 0.15
- 타부서근거: 다른 부서 항목 점수 ≥ 0.45 이고 자기 부서 최고점보다 0.15 이상 높음. 문구 틀(위원회·조성·공모사업·추진·관리 등)을 지운 뒤에도 0.35 이상 닮아야 하고, 과태료, 과징금처럼 부서마다 자기 법령으로 하는 일은 표시하지 않음
- 공통사무(총괄부서 근거): 타부서근거 조건을 만족하고 업무에 아래 공통사무 낱말이 있음(총괄부서 자신의 업무는 제외). 근거1에 총괄부서 조항을 달고 자기 부서 상위 2개는 근거2·3으로 옮김. 타부서근거에서는 뺌
- 일반 업무명: 다섯 글자 미만이거나 '통계업무'·'청사관리'·'시설물 유지관리'처럼 일반적인 이름이면 직접근거·타부서근거를 주지 않음(최대 후보)

점수는 문구가 얼마나 닮았는지일 뿐 관할 판단의 정답 확률이 아닙니다.
