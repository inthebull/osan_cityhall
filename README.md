# 오산시 AI 청사

2026 오산시 시정연구모임 F4O(Future 4 Osan) 팀의 연구 결과물입니다.
오산시청 내부를 2D 디지털 트윈으로 옮기고, 그 안에서 AI 주무관이 세 가지 일을 합니다.

1. **AI 인수인계**: 업무 카드, 연간 달력, 단계 체크리스트, 후임자 질의응답
2. **AI 업무배분**: 애매한 업무를 근거와 점수로 부서에 배정 (점수는 코드가 계산)
3. **업무도구 축적**: AI가 만든 업무 도구가 사람이 아니라 업무에 쌓여 후임자에게 승계

AI 주무관은 민원여권과, 노인장애인과, 동 행정복지센터 세 곳에서 먼저 근무합니다.

## 실행
```
npm install
npm run dev      # http://localhost:3000
```

## 문서
- `CLAUDE.md` 개발 원칙 (클로드 코드가 먼저 읽음)
- `docs/00_팀원공유_상세기획.md` 팀원 공유용 기획
- `docs/02_기술설계서.md` 구조·데이터·알고리즘
- `docs/03_개발작업순서.md` 주차별 작업 지시문
- `docs/04_외부스킬목록.md` 가져온 외부 스킬과 출처
- `docs/research_오산시청_청사배치.md` 청사 배치 조사 결과 (확인/추정/미확인 표시)
