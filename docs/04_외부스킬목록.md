# 04. 외부 스킬·서브에이전트 목록

공개 GitHub에서 찾은 Claude Code 스킬(SKILL.md)과 서브에이전트 중, "오산시 AI 청사"(Next.js App Router + TypeScript + Tailwind, SVG 청사 지도, AI 인수인계·업무배분·업무도구 축적, Vitest/Playwright, Vercel)를 만드는 데 실제로 도움이 되는 것만 골라 가져왔다.

- 가져온 날짜: 2026-10-30
- 원칙: 공식/고평가 저장소, MIT·Apache-2.0 라이선스, 외부 통신·유료 서비스·설치 스크립트가 없는 것만. 모든 SKILL.md와 딸린 파일을 끝까지 읽고 수상한 지시가 없음을 확인한 뒤 원문 그대로 복사했다.
- 각 스킬 폴더에 `LICENSE`(또는 `LICENSE.txt`)와 `SOURCE.md`(저장소 URL, 커밋, 라이선스)가 있다. 서브에이전트는 파일 끝 주석에 출처를 적었다.
